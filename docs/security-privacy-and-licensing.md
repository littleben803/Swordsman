## 总体原则

当前目标平台是 macOS，不代表历史移动端功能已经清除。代码中仍有网络、激活、日志上传和支付相关实现，发行或恢复功能前必须确认真实数据流和服务状态。云存档已于2026-11-12移除。

未经用户明确授权：

- 不新增或启用网络请求。
- 不连接历史生产服务试探。
- 不新增账号、登录、分析、广告、支付、云同步或在线 AI。
- 不申请新的系统权限。
- 不输出、保存或提交凭据和用户数据。

Development Build 当前启用了 `AllowDebugging`，运行时会打开托管调试监听并发送 Unity Player discovery 组播。这只允许用于受控的本地开发环境；发布构建必须关闭 Development Build/Script Debugging 并重新检查网络行为。

## 已发现的历史能力

### 网络访问

`Assets/Scripts/Base/GamePHP.cs` 使用 `UnityWebRequest` 实现历史服务端通信，仍涉及调试存档上传/下载、激活、日志或平台校验。文档和日志中不得复制真实服务地址、参数或用户标识。修改前应确认服务所有权、TLS、认证、超时、重试、错误提示和数据保留政策。

### 2026-11-14 设置页外链与评价退役

按产品授权删除6个帮助/攻略/QQ群入口及其外链、加群调用，删除评价入口、商店评价跳转和评价状态读写。Stage=31相关事件统一按熟练度25点判断，不再以评价状态给予优惠。其他历史网络/激活/支付接口未扩围修改，不能据此宣称项目完全离线。新增虚拟键盘开关只保存本机PlayerPrefs，不增加网络、账号、权限或存档字段。

### 云存档

2026-11-12按产品决定移除云同步：标题/营地入口、云面板及脚本、云文案、云槽位缓存、上传下载回调和 `SWORD_CLOUD` 分支全部删除。存读档仅保留本地文件，槽位、3000字节普通档格式及战斗临时档不变。其他历史调试上传、激活、日志和支付不属于云同步，本轮未启用；这不代表项目已完全离线。

### 日志上传

代码存在把错误信息交给历史网络层的路径。日志可能包含堆栈、设备环境和运行状态。启用前必须列出字段并脱敏，禁止上传存档、稳定设备标识或凭据。

### 激活与支付

工程保留 Android 激活、iOS 条件编译校验以及 `DllImport("__Internal")` 支付/原生接口。不得自行迁移、模拟、绕过或删除；去留属于产品和合规决定。

## 本地数据

玩家设置通过 `PlayerPrefs` 保存，进度和战斗状态主要位于 `Application.persistentDataPath`。

- 不在日志中打印完整存档或用户输入。
- 处理损坏存档时保留原文件，避免静默覆盖。
- 迁移必须支持失败回退并说明备份位置。
- 不把真实用户存档加入 Git、测试夹具或问题附件。
- 未来引入沙盒、签名或公证流程时，验证持久化目录迁移行为。
